Detailed Description

template<typename Generator, typename Value>
class ldsgen::GeneratorIterator< Generator, Value >

Forward iterator for sequence generators.

Provides STL-compatible iterator interface for all generators. Allows use in range-based for loops and STL algorithms.

* VdCorput gen(2);
* std::vector<double> points(gen.begin(), gen.begin() + 100);

Dereference operator (read-only).

Reads the value at the current sequence position through the generator's pure value_at() computation. Because pop() is defined as value_at(++count_) and the begin() index is 0, the value at iterator position index is value_at(index + 1). Dereferencing therefore never mutates the generator, keeping iteration a read-only operation (and free of the previous reseed/pop/reseed state churn on the atomic counter).

Note
Requires the IndexableGenerator refinement (pure value_at).
